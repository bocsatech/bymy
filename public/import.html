Hasznaltauto.hu import

Import után az „Összes mentése” gomb egyszerre menti az összes betöltött hirdetést (nem kell egyesével). Import közben is mentődnek; a gomb a hiányzókat pótolja, a duplikátumokat átugorja.

Import hasznaltauto.hu-ról

Lista vagy egy hirdetés URL-jét illeszd be — első 20 db, fő képpel. Csak adatolvasás; nem ad fel hirdetést a Használtautó.hu-ra.

1) Import indítása → látható Chrome + első 20 auto mentése (feladott)   2) Cloudflare pipa ha kell   3) Duplikátumok kimaradnak; új lista URL = hozzáadódik (pl. 80 autó)
